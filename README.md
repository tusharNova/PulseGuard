# PulseGuard

A modern uptime monitoring platform built to track the availability and response time of websites and APIs. This project is being built over a 28-day challenge focusing on full-stack development, background jobs, and containerization.

## 🚀 Tech Stack

**Backend**
- Django & Django REST Framework
- PostgreSQL (Database)
- Celery (Background Tasks)
- Redis (Message Broker)

**Frontend**
- React & TypeScript (Vite)
- Recharts (Data Visualization)

**DevOps**
- Docker & Docker Compose
- Nginx
- GitHub Actions (CI/CD)

## 🎯 28-Day Challenge
This project is being developed as part of a 28-day learning and coding challenge:
*   **Daytime:** Researching and learning new concepts (e.g., Celery, JWT, TypeScript).
*   **Nighttime:** Implementing what was learned by writing documentation and committing code (goal: 5 commits/day).

👉 Check out the [TASK.md](TASK.md) file to see the day-by-day roadmap and progress!
