# PulseGuard

A modern uptime monitoring platform built with Django, Django REST Framework, React, and TypeScript.

## Tech Stack

- Django
- Django REST Framework
- React
- TypeScript
- PostgreSQL
- Celery
- Redis
- Docker
- Nginx
